# jComercial

Un proyecto para facturar y contratar en el CNCI de Cienfuegos
------------------
PASOS A SEGUIR
------------------
1 - Instalar composer globalmente en la PC vease https://getcomposer.org/
2 - Desde la directorio de la aplicación ejecutar una shell con el comando composer install
3-  Desde la misma shell ejecutar el comando ./bin/console doctrine:migration:migrate
4 - Listo!!!!
